Topic overview

AI Engineering

Designing, building, and debugging agent systems from first principles: the read-act-observe loop, tool schemas and their failure surfaces, context and memory management, and how to diagnose a broken agent layer by layer. The environment this course is written and read in — a live agentic coding harness — is used throughout as a running, honestly-described example, not a black box to reverse-engineer.
