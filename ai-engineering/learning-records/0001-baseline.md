# Baseline: Systems Builder, Not a Prompt-Tips Seeker

The user wants to move from being a user of agentic AI systems to a credible builder of them, with direct access to a live agent harness (this very environment) as a running example throughout. Strong existing CS/systems background (Rust/C, comfortable with real code and architecture) means lessons can move straight into pseudocode, JSON tool schemas, and architecture-level diagnosis rather than building up from "what is an LLM" basics.

**Implications:** Every lesson should ground new concepts in how the user's own environment plausibly works (system prompt, tool schemas, the loop, context management, subagent delegation) — described honestly and generically, never as a fabricated claim about a specific vendor's internals. Skip prompt-wording tips entirely; the course is scoped one level up, at the systems/architecture layer, per the mission's explicit out-of-scope note.
