# Baseline: Comprehensive Course, Building on Quantum Mechanics

User asked for "a very comprehensive course on quantum computing... understand it fundamentally and intuitively," directly after finishing the core of [[../../quantum-mechanics/learning-records/0001-baseline.md|Quantum Mechanics]] (state vectors, Born rule, entanglement, Bell's theorem, unitary evolution) — exactly the prerequisite that mission's own scope note flagged for this future topic.

**Implications:** No need to re-derive linear algebra, ket notation, or the Born rule — start straight from "a qubit is a vector you already know how to write down" and move immediately into gates and circuits. Given the "comprehensive" framing, the full 10-lesson roadmap was scoped and written into the topic index up front (lessons 1-6 built this session, 7-10 as a visible locked roadmap) rather than extended one lesson at a time, matching the user's stated intent to see the whole course.
