Universal Gates, Reversibility & No-Cloning

Two lessons in, you've been told every gate must be unitary without being told exactly why that's such a strong restriction, or what it rules out. This lesson closes both gaps: it shows what "every gate is reversible" actually forbids compared to ordinary classical logic, what a small set of gates can still build despite that restriction, and proves — with nothing but the linearity you already use every day — a genuinely surprising fact: you cannot copy an unknown qubit.

Reversible by construction

A unitary matrix always has an inverse — U−1 = U†, guaranteed, for every unitary U. So every quantum gate is automatically reversible: given the output, you can always compute exactly which input produced it, just by applying the gate backwards.

Ordinary classical logic gates don't have this property. Take AND:

0 AND 0 = 0
0 AND 1 = 0
1 AND 0 = 0
1 AND 1 = 1

Three different inputs produce the same output, 0. Given only the output "0," there's no way to recover which input it came from — information was thrown away. That's exactly what "not reversible" means, and it's true of most classical logic (AND, OR, NAND — anything with more input bits than output bits).

The physics isn't a coincidence Landauer's principle says erasing one bit of information necessarily dissipates at least a small, fixed amount of heat — irreversible computation is thermodynamically irreversible too. Reversible gates aren't just a quirk of quantum mechanics; they're the only kind of computation that could, in principle, be done with zero energy dissipation.

Making classical logic reversible: the Toffoli gate

You don't have to give up classical computation to keep everything reversible — you just need one extra output. The Toffoli gate (CCNOT) takes three bits, flips the third only if both the first two are 1, and leaves everything else alone:

Toffoli(a, b, c) = (a, b, c ⊕ (a AND b))

Set c = 0 going in, and the third output becomes exactly a AND b — while the first two inputs are preserved on the outputs, so nothing is lost and the gate is its own inverse (apply it twice and you're back where you started). Toffoli alone, plus fixed 0/1 inputs (called ancilla bits) and wires you simply ignore at the end, can reproduce any classical logic circuit reversibly. That makes Toffoli universal for classical reversible computation — every classical algorithm has a reversible, and therefore quantum-gate-compatible, version.

Universal for quantum computation

Toffoli plus reversibility gets you classical computation back. But quantum computing also needs superposition and relative phase, which Toffoli alone can't produce (it only ever permutes basis states — feed it a definite input, get a definite output). Add the Hadamard gate for superposition and the T gate for fine phase control, and the set {H, T, CNOT} becomes universal for all of quantum computing: any unitary on any number of qubits can be approximated to arbitrary precision using only gates from this set (a result called the Solovay-Kitaev theorem). This is the quantum-circuit analogue of NAND being universal for classical logic — a small, fixed toolkit that's provably enough for everything.

You cannot copy an unknown qubit

Here's a question a classical programmer would never think to ask: can you build a gate that copies a qubit — takes |ψ⟩ (in any state, unknown to you) and produces |ψ⟩|ψ⟩? In classical computing, copying a bit is free and constant. In quantum computing, it's impossible, and the proof uses nothing beyond what you already have.

Proof: assume a cloning gate exists, then contradict it Suppose a unitary U existed with U(|ψ⟩|0⟩) = |ψ⟩|ψ⟩ for every single-qubit state |ψ⟩ — a universal copier. In particular it must work on the two basis states:
U(|0⟩|0⟩) = |0⟩|0⟩ and U(|1⟩|0⟩) = |1⟩|1⟩.

Now feed it the superposition (|0⟩+|1⟩)/√2 instead. Every unitary operator is linear, so U must distribute over the sum:
U((|0⟩+|1⟩)/√2 ⊗ |0⟩) = (U(|0⟩|0⟩) + U(|1⟩|0⟩))/√2 = (|00⟩ + |11⟩)/√2

That's the entangled Bell state from lesson 2. But true cloning of (|0⟩+|1⟩)/√2 should have produced two independent copies of that same state:
[(|0⟩+|1⟩)/√2] ⊗ [(|0⟩+|1⟩)/√2] = (|00⟩ + |01⟩ + |10⟩ + |11⟩)/2

(|00⟩+|11⟩)/√2 ≠ (|00⟩+|01⟩+|10⟩+|11⟩)/2 — linearity forces the entangled state, not the product-state "two copies" a real cloner would need to produce. No unitary can satisfy the cloning equation for every input state. This is the no-cloning theorem.

Notice the proof never used anything specific to qubits — only that U is linear (because it's unitary) and is assumed to work on every input state, including superpositions of states it already handles correctly individually. That's why no-cloning is a theorem, not an engineering limitation waiting on better hardware.

This is also why quantum error correction (lesson 9) can't use the classical trick of "make three copies and take a majority vote" — and why quantum key distribution protocols like BB84 can detect eavesdropping: an eavesdropper physically cannot make an undetectable copy of a qubit in transit to inspect later.
