The Quantum Fourier Transform & Phase Estimation

Grover's algorithm amplified an amplitude you could point at with an oracle. This lesson builds a different tool: one that reads out periodicity — and a general-purpose subroutine, phase estimation, that generalizes lesson 4's phase kickback from a single bit to an arbitrary real number. Both are the machinery Shor's algorithm is built from.

From Fourier transform to quantum Fourier transform

The classical discrete Fourier transform turns a signal into its frequency components. The quantum Fourier transform (QFT) is the same linear transformation, applied to the amplitudes of a quantum state over N = 2ⁿ basis states:

QFT|x⟩ = (1/√N) Σ_y  e^(2πixy/N) |y⟩          for x = 0, ..., N−1

Feed it one basis state |x⟩, and it outputs a superposition over every basis state |y⟩, with phases that spin around the unit circle at a rate set by x. The reason this is useful for computing has nothing to do with signal processing directly — it's that the QFT takes a state whose amplitudes are periodic and concentrates the output almost entirely onto basis states related to that period. That's the property Shor's algorithm exploits: turn "find a hidden period" into "prepare a periodic state, apply QFT, measure."

The smallest case is a gate you already know

For n=1 (N=2), the QFT formula reduces to exactly the Hadamard gate:

QFT|0⟩ = (1/√2)(|0⟩ + |1⟩) = H|0⟩
QFT|1⟩ = (1/√2)(|0⟩ − |1⟩) = H|1⟩

Every H gate you've used since lesson 1 was already a 1-qubit Fourier transform. The n-qubit QFT is what you get by generalizing H's role — "spread a basis state into an equal superposition with structured phases" — to N basis states instead of 2.

Building it from gates you already have

The QFT circuit is built entirely from Hadamards and controlled phase-rotation gates R_k = diag(1, e^(2πi/2^k)) — a generalization of the S and T gates from lesson 1, which are exactly R₂ and R₃. The full n-qubit circuit uses O(n²) gates total.

O(n²) gates ≠ "reading out" the transformed vector A classical Fast Fourier Transform on N = 2ⁿ data points takes O(n·2ⁿ) time but gives you back all N transformed values, fully readable. The quantum circuit is exponentially cheaper to run — but it only prepares the transformed amplitudes inside a quantum state, and a single measurement only samples one basis state from it, per the Born rule, exactly the same caveat lesson 2 raised about exponential state spaces in general. The QFT is a component inside a larger algorithm, never a drop-in replacement for "compute the classical FFT, fast."

Phase estimation: reading out an eigenvalue's phase

Here's the general problem phase estimation solves: given a unitary U and one of its eigenvectors |u⟩ (so U|u⟩ = e2πiφ|u⟩ for some unknown φ ∈ [0,1)), estimate φ.

Start with a single control qubit, exactly like lesson 4's derivation:

(|0⟩+|1⟩)/√2 ⊗ |u⟩  --controlled-U-->  (|0⟩|u⟩ + e^(2πiφ)|1⟩|u⟩)/√2  =  [(|0⟩ + e^(2πiφ)|1⟩)/√2] ⊗ |u⟩

This is exactly phase kickback again — φ lands on the control qubit as a phase, and |u⟩ is completely untouched, so no entanglement lingers. The only thing new is that φ can now be any real number in [0,1), not just 0 or 1/2 — lesson 4's O_f was the special case φ ∈ {0, 1/2}, since (−1)^f(x) = e2πiφ exactly when φ is 0 or 1/2.

To read out more than one bit of φ, use t control qubits instead of one, each in |+⟩, and let control qubit j apply U2ʲ (U raised to the 2ʲ power) instead of plain U. Kickback then puts a phase of e2πiφ·2ʲ on control qubit j, and together the t control qubits end up holding:

(1/√2^t) Σ_(k=0)^(2^t−1)  e^(2πiφk) |k⟩

which is exactly the kind of periodic, phase-structured state the QFT is built to decode. Apply the inverse QFT to this register and measure: the result is φ, expressed to t bits of binary precision.

Worked example: φ = 1/4, t = 2 control qubits With t=2, N=4, the control register ends up in (1/2)[e^(2πi·(1/4)·0)|0⟩ + e^(2πi·(1/4)·1)|1⟩ + e^(2πi·(1/4)·2)|2⟩ + e^(2πi·(1/4)·3)|3⟩] = (1/2)[|0⟩ + i|1⟩ − |2⟩ − i|3⟩].

Compare this to the QFT formula applied directly to |1⟩ with N=4: QFT|1⟩ = (1/2)Σ_y e^(2πi·1·y/4)|y⟩ = (1/2)[|0⟩ + i|1⟩ − |2⟩ − i|3⟩] — the identical vector. So the control register above is QFT|1⟩, which means the inverse QFT maps it back to exactly |1⟩. Measuring gives k=1 with certainty, and k/2ᵗ = 1/4 = φ, recovered exactly.

φ = 1/4 was chosen because it's exactly representable in 2 bits (φ = 0.01 in binary); in general φ won't be exactly representable in t bits, and the algorithm returns the closest t-bit estimate with high probability rather than a guaranteed-exact answer. More control qubits buy more precision, at the cost of a longer circuit.
